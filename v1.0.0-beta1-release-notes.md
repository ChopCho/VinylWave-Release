# VinylWave v1.0.0-beta1 — Early Public Beta

Welcome to the initial public beta release of **VinylWave** for legacy 32-bit iOS!

VinylWave is a retro vinyl-themed music player designed to bring YouTube Music streaming back to legacy iOS devices, specifically optimized for the Apple A6 architecture (iPhone 5).

---

## What's Included

- **iOS Application Binary:** `VinylWave-iPhone5-armv7-v49-b14c.ipa` (32-bit ARMv7 Mach-O executable)
- **Integrity Manifest:** `SHA256SUMS.txt`

---

## Highlights & Features

- **Retro Vinyl Aesthetic:** Animated turntable with rotating vinyl record, needle drop interaction, and smooth 60fps arm tracking.
- **Background Audio Streaming:** Listen continuously while using other apps or with the device screen locked.
- **Lock Screen Artwork & Controls:** Native lock screen player controls with album cover integration.
- **Search & Trending Catalog:** Search artists, albums, and tracks directly from YouTube Music.
- **Classic iPod Mode:** Optional iPod click-wheel navigation mode for an authentic retro experience.
- **RAM Conscious:** Built with strict memory management tailored for devices with 1 GB or less of RAM.

---

## Device & Firmware Support

- **Target Device:** iPhone 5 (`iPhone5,1` / `iPhone5,2`), iPad (4th generation), iPod touch (5th generation).
- **Target OS:** iOS 6.0 through iOS 10.3.4 (Optimized for iOS 10.3.4).
- **Architecture:** 32-bit ARMv7 (`armv7`).

---

## Installation Prerequisites

- **Jailbreak + AppSync Unified:** Required when installing ad-hoc signed `.ipa` packages on jailbroken devices to prevent signature verification errors and certificate revocation. Install AppSync Unified (`ai.akemi.appsyncunified`) via Zebra or Cydia from Karen's Repo (`https://cydia.akemi.ai/`). If sideloading with a personal Apple ID profile, AppSync Unified is optional.
- **appinst (App Installer):** Recommended for direct on-device installation. Available from Karen's Repo (`https://cydia.akemi.ai/`) as package `ai.akemi.appinst` via Zebra or Cydia. Allows installing the `.ipa` via terminal or SSH (`appinst <path-to-ipa>`).
